# Security Policy

## Supported versions
Only the latest released version (and `master`) receives security fixes.

## Reporting a vulnerability
Please report privately. Do **not** open a public issue.

1. Go to <https://github.com/jazzplato/myip/security/advisories/new> (GitHub private vulnerability reporting).
2. Describe the impact, affected version and a reproduction.

This is a single-maintainer project, so responses are best effort. Fixes are prepared privately in the advisory and disclosed together with the release.

## Scope
`myip` makes outbound HTTPS requests and prints the response. Reports about the third-party services it queries (for example ipinfo.io) belong with those services.
