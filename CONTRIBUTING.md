# Contributing

Ideas and bug reports are welcome. The workflow is: **idea -> spec -> ready -> PR -> CI gates -> human merge**. Details: [docs/process.md](docs/process.md).

- Open an issue from a template (blank issues are disabled). Start with `Idea` if you are unsure.
- Send a PR only for an issue labeled `stage:ready`. One issue -> one small PR; use the PR template and paste evidence.
- Before pushing, run the checks listed in [AGENTS.md](AGENTS.md). It applies to humans and agents alike.
- Security problems: see [SECURITY.md](SECURITY.md), not a public issue.
